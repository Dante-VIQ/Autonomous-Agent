# Cron job for Hostinger shared hosting
# Run every 15 minutes. run.py executes ONE cycle and exits (main.py's
# run_forever loop is for long-running processes, not cron). Overlapping runs
# are prevented by a per-brand file lock (set AGENT_LOCK_DIR to a writable dir).
*/15 * * * * cd /home/your_username/python-agent && /usr/bin/python3 run.py >> logs/agent.log 2>&1
